# دانلود استوری اینستاگرام

این قابلیت **پیش‌فرض خاموش** است. از **🎨 شخصی‌سازی ← 📷 اینستاگرام ← ⚙️ تنظیمات ← 📥 دانلود استوری اینستاگرام** روشنش کن. کوکی ورود معتبر را از **ایمپورت کوکی ← اینستاگرام** وارد کن؛ همان مخزن چندکوکی و پروکسی اینستاگرام استفاده می‌شوند و حتی در حالت «کوکی فقط هنگام نیاز»، استوری از نشست ورود استفاده می‌کند.

سه راه دریافت:

- لینک یک استوری: `https://www.instagram.com/stories/USERNAME/123456789/`؛ فقط همان استوری فرستاده می‌شود.
- دستور `/story_instagram USERNAME` یا لینک `https://www.instagram.com/stories/USERNAME/`؛ استوری‌های فعال قابل‌دسترسی برای نشست ربات دریافت می‌شوند.
- دکمهٔ **📥 دانلود استوری‌ها** زیر پروفایلی که با آیدی یا لینک باز کرده‌ای. این دکمه فقط برای درخواست‌دهنده و همان گفت‌وگو و موضوع فعال است؛ هنگام دریافت، کلیک تکراری درخواست دیگری ایجاد نمی‌کند.

انتخاب کیفیت وجود ندارد. عکس/ویدیو تکی مستقیم می‌آید؛ چند استوری در یک پیام با قبلی/بعدی ورق می‌خورند، همراه صدای ویدیو. استوری حساب‌های همسایه یا پیشنهادشده به خروجی اضافه نمی‌شود. لینک یک استوری منقضی‌شده هم به استوری دیگری تبدیل نمی‌شود. تا ۱۰۰ آیتم در هر درخواست پذیرفته می‌شود؛ فهرست بزرگ‌تر کامل رد می‌شود و بی‌سروصدا بریده نمی‌شود. سقف پست‌های معمولی همان ۲۰ اسلاید است.

فقط استوری فعال و قابل دسترسی با کوکی ربات پشتیبانی می‌شود؛ آرشیو گذشته، هایلایت و محتوای حساب خصوصیِ خارج از دسترسی نشست دانلود نمی‌شوند. خروجی مقاله برای استوری استفاده نمی‌شود، حتی اگر مقاله برای پست‌ها روشن باشد. وقتی استوری فعالی برای نشست در دسترس نباشد، یک پیام معمولیِ «استوری در دسترس نیست» می‌آید.

کلید استوری مستقل از نمایش پروفایل است. خاموش‌کردنش جلوی درخواست‌های جدید، پردازش درخواستِ صف‌شده و ورق‌زدن بعدی را می‌گیرد. دسترسی عمومی ربات، فقط مدیرها، گروه‌ها و مالکیت موضوع در همهٔ مسیرها رعایت می‌شوند. در پاسخ 429، پردازش بدون امتحان‌کردن کوکی/مسیر دیگر متوقف می‌شود؛ واردکردن کوکی به‌تنهایی تضمین نمی‌کند IP سرور محدود نشده باشد.

در **🎨 شخصی‌سازی ← اینستاگرام ← 📥 کپشن، متن‌ها و دکمه‌های استوری** کپشن تکی و چندتایی، پیام‌های وضعیت/خطا، نام و رنگ و ایموجی معمولی/پریمیوم دکمه‌ها ویرایش می‌شوند. متغیرهای کپشن: `{username}`، `{index}`، `{count}`، `{description}` و `{url}`. چیدمان استوری تکی و چندتایی جداست. نمایش دکمهٔ منبع از کلید منبع اینستاگرام پیروی می‌کند و عنوان/ظاهرش مخصوص استوری است؛ پیش‌فرض منبع خاموش است.

دریافت و تبدیل از gallery-dl پین‌شده و مسیر مشترک GalleryMedia می‌گذرد؛ پیام‌های چندتایی از همان مالکیت، نسخهٔ ناوبری، موضوع و cache تأییدشدهٔ Telegram استفاده می‌کنند. فایل ارسال‌شده پس از تأیید آزاد می‌شود؛ استوری‌های هنوز نمایش‌داده‌نشده برای ورق‌زدن تا ۲۴ ساعت در cache خصوصی می‌مانند و در بکاپ نیستند. آمار سرعت نیز از مسیر مشترک گزارش می‌شود.

تست محلی شامل استخراج‌کنندهٔ واقعی، FFmpeg، HTTP و API تلگرام آزمایشی است. این تست موفقیت زندهٔ سرور محدودشدهٔ اینستاگرام را تأیید نمی‌کند.
