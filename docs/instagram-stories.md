# دانلود استوری اینستاگرام

این قابلیت **پیش‌فرض خاموش** است. از **🎨 شخصی‌سازی ← 📷 اینستاگرام ← ⚙️ تنظیمات ← 📥 دانلود استوری اینستاگرام** روشنش کن. کوکی ورود معتبر را از **ایمپورت کوکی ← استوری اینستاگرام** وارد کن؛ مخزن چندکوکی مستقل استوری و پروکسی اینستاگرام استفاده می‌شوند و حتی در حالت «کوکی فقط هنگام نیاز»، استوری از نشست ورود استفاده می‌کند.

دو راه دریافت:

- لینک یک استوری: `https://www.instagram.com/stories/USERNAME/123456789/`؛ فقط همان استوری فرستاده می‌شود.
- دستور `/insta USERNAME` یا لینک `https://www.instagram.com/stories/USERNAME/`؛ استوری‌های فعال قابل‌دسترسی برای نشست ربات دریافت می‌شوند.

انتخاب کیفیت وجود ندارد. عکس/ویدیو تکی مستقیم می‌آید؛ چند استوری در یک پیام با قبلی/بعدی ورق می‌خورند، همراه صدای ویدیو. استوری حساب‌های همسایه یا پیشنهادشده به خروجی اضافه نمی‌شود. لینک یک استوری منقضی‌شده هم به استوری دیگری تبدیل نمی‌شود. تا ۱۰۰ آیتم در هر درخواست پذیرفته می‌شود؛ فهرست بزرگ‌تر کامل رد می‌شود و بی‌سروصدا بریده نمی‌شود. سقف پست‌های معمولی همان ۲۰ اسلاید است.

فقط استوری فعال و قابل دسترسی با کوکی ربات پشتیبانی می‌شود؛ آرشیو گذشته، هایلایت و محتوای حساب خصوصیِ خارج از دسترسی نشست دانلود نمی‌شوند. خروجی مقاله برای استوری استفاده نمی‌شود، حتی اگر مقاله برای پست‌ها روشن باشد. وقتی استوری فعالی برای نشست در دسترس نباشد، یک پیام معمولیِ «استوری در دسترس نیست» می‌آید.



دریافت و تبدیل از gallery-dl پین‌شده و مسیر مشترک GalleryMedia می‌گذرد؛ پیام‌های چندتایی از همان مالکیت، نسخهٔ ناوبری، موضوع و cache تأییدشدهٔ Telegram استفاده می‌کنند. فایل ارسال‌شده پس از تأیید آزاد می‌شود؛ استوری‌های هنوز نمایش‌داده‌نشده برای ورق‌زدن تا ۲۴ ساعت در cache خصوصی می‌مانند و در بکاپ نیستند. آمار سرعت نیز از مسیر مشترک گزارش می‌شود.

تست محلی شامل استخراج‌کنندهٔ واقعی، FFmpeg، HTTP و API تلگرام آزمایشی است. این تست موفقیت زندهٔ سرور محدودشدهٔ اینستاگرام را تأیید نمی‌کند.

کوکی استوری در `storage/instagram-stories-cookies.txt` و مخزن جانبی خودش نگه‌داری می‌شود؛ کوکی پست در `instagram-cookies.txt` می‌ماند. ایمپورت، برچسب، نمایش، خروجی گرفتن، حذف، بررسی انقضا و وضعیت خرابی این دو مستقل‌اند. کوکی قبلی پست خودکار کپی یا به‌عنوان جایگزین استفاده نمی‌شود. برای استقلال واقعی نشست‌ها، کوکی یک نشست مرورگر جدا را در پنل استوری وارد کن؛ استفاده از همان کوکی در دو محل، تاریخ انقضای آن نشست را عوض نمی‌کند. محدودیت IP مانند 429 همچنان ممکن است روی هر دو اثر بگذارد.

کامند `/insta rahkar_mobile` مستقیماً درخواست استوری ثبت می‌کند. استخراج‌کننده فقط شناسهٔ حساب را از صفحهٔ معتبر همان پیج می‌گیرد و query اطلاعات کامل پروفایل را فراخوانی نمی‌کند؛ آن query قبلاً می‌توانست خطای دسترسی را به NotFound و سپس restricted تبدیل کند. خطاهای دریافت شناسه و دریافت reel اکنون با مرحلهٔ ثابت و HTTP عددی مشخص می‌شوند. این اصلاح رفع محدودیت زندهٔ سرور را تضمین نمی‌کند.

نمایش عکس پروفایل و بیو، دریافت آیدی خام و کامند `/user_instagram` حذف شده‌اند؛ کارهای قدیمی صف‌شده لغو و دکمه‌های قدیمی غیرفعال می‌شوند. استوری با لینک یا کامند باقی می‌ماند. از **🎨 شخصی‌سازی ← اینستاگرام ← استوری** کپشن‌ها، متن‌ها، خطاها و دکمه‌ها و از تنظیمات همان بخش کلید استوری را ویرایش کن. استوری پیش‌فرض خاموش است و همچنان به کوکی مستقل نیاز دارد.

متن پیش‌فرض راهنمای `/insta` از **شخصی‌سازی ← اینستاگرام ← کپشن، متن‌ها و دکمه‌های استوری ← راهنمای دریافت استوری** ویرایش می‌شود. `{bot_username}` آیدی خود ربات را در انتهای متن قرار می‌دهد. نسخه‌های ذخیره‌شدهٔ دقیقِ راهنمای پیش‌فرض قدیمی به متن جدید منتقل می‌شوند؛ متن سفارشی عمدی حفظ می‌شود.
