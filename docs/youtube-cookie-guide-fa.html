فایل را به سرور منتقل کن

این بخش روی ویندوز انجام می‌شود؛ هنوز لازم نیست داخل SSH سرور باشی.

۶

روی ویندوز: انتقال فایل با PowerShell

PowerShell را باز کن. در دستور زیر، SERVER_IP را با IP واقعی سرور عوض کن؛ سپس دستور را اجرا کن:

cd "$env:USERPROFILE\Downloads"
scp .\youtube-cookies.txt root@SERVER_IP:/root/youtube-cookies.txt

این دستور فرض می‌کند فایل در Downloads است و کاربر SSH سرور، root است. اگر پورت SSH متفاوت است، گزینهٔ -P PORT را بعد از scp اضافه کن. رمز هنگام تایپ نمایش داده نمی‌شود؛ این طبیعی است.

اگر مطمئن نیستی فایل کجا ذخیره شده

در File Explorer وارد Downloads شو و فایل را پیدا کن. برای بررسی مسیر پیش‌فرض می‌توانی در PowerShell این دستور را اجرا کنی:

Get-Item "$env:USERPROFILE\Downloads\youtube-cookies.txt"

این دستور فقط مشخصات فایل را نشان می‌دهد؛ محتوای کوکی را باز نمی‌کند.

از منوی مدیریت، تست واقعی بگیر

اول با حساب ادمین، گفت‌وگو با ربات را باز کن و /start بفرست. سپس در منوی سرور گزینهٔ ۸ — Run delivery diagnostics را انتخاب کن.

وقتی URL خواست، یک لینک عمومی و کوتاه یوتیوب وارد کن؛ مثلاً:

https://www.youtube.com/watch?v=ybNMMK5Q318

ویدیو به اولین شناسهٔ موجود در ADMIN_IDS ارسال می‌شود. منتظر نتیجهٔ دانلود و آپلود بمان.

با واردکردن لینکدانلود واقعی از یوتیوب و سپس ارسال فایل به تلگرام تست می‌شود.
با Enter بدون لینکفقط ویدیوی محلی ساخته و آپلود می‌شود؛ دسترسی یوتیوب تأیید نمی‌شود.

نتیجهٔ موفق

All diagnostic checks passed.

علاوه بر این پیام، باید فایل ویدیو را در تلگرام ادمین ببینی. بعد، یک لینک معمولی برای خود ربات بفرست تا مسیر روزمرهٔ صف و دانلود هم بررسی شود.
