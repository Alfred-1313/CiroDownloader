# افزودن ادمین با نام‌کاربری

از نسخهٔ 1.15.0، در پی‌وی از **⚙️ پنل مدیریت ← ➕ افزودن ادمین** استفاده کن و نام‌کاربری را به‌شکل `@ExampleUser` بفرست. نام بدون `@` هم پذیرفته می‌شود؛ آیدی عددی پذیرفته نمی‌شود.

کاربر ابتدا باید در پی‌وی ربات `/start` کند تا نام‌کاربری حسابش برای ربات شناخته شود. برای کاربرانی که پیش از اضافه‌شدن این قابلیت از ربات استفاده کرده‌اند نیز یک `/start` تازه لازم است. Bot API امکان جست‌وجوی دلخواه حساب‌های شخصی با نام‌کاربری را نمی‌دهد؛ حساب شناخته‌شده پیش از ثبت دوباره بررسی می‌شود. نام‌کاربری تغییرکرده یا پاسخ ناموفق باعث اعطای دسترسی نمی‌شود.

ادمین جدید به ابزارهای پنل، کوکی‌ها، تنظیمات، افزودن ادمین و به‌روزرسانی دسترسی دارد. دسترسی فوراً فعال می‌شود و با راه‌اندازی مجدد باقی می‌ماند. ادمین جدید می‌تواند `/admin` یا `/start` را بفرستد تا پنل را باز کند. این کار فقط در پی‌وی و توسط یک ادمین موجود ممکن است. «بازگشت» یا `/cancel` ورود نام را لغو می‌کند؛ مهلت ورود ۱۰ دقیقه است.

ادمین‌های اولیه از `ADMIN_IDS` باقی می‌مانند و این ابزار فایل تنظیمات سرور را تغییر نمی‌دهد. دسترسی‌های اضافه‌شده در داده‌های ربات نگه‌داری می‌شوند و به حساب وصل‌اند؛ تغییر نام‌کاربری یا واگذاری آن به شخص دیگر، دسترسی را به آن شخص منتقل نمی‌کند. ربات، پردازشگر و سرویس به‌روزرسانی فقط دسترسی‌هایی را می‌پذیرند که زنجیرهٔ اعطای آن‌ها به ادمین‌های اولیه برسد. بکاپ SQLite این دسترسی‌ها را نیز نگه می‌دارد.
