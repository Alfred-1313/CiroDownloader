# دستورهای مدیر

وقتی **⚙️ پنل مدیریت** را باز می‌کنی (دکمه یا `/admin`)، پیام پنل این‌ها را نشان می‌دهد:

- **📜 دستورها:** فهرست همهٔ دستورهای مدیر با یک توضیح کوتاه، به‌شکل قابل‌لمس.
- **🧭 راهنمای استفاده:** چند خط کوتاه دربارهٔ دکمه‌ها، گزارش‌ها، کوکی‌ها، افزودن مدیر و `/cancel`.

همان فهرست در منوی «/» تلگرام همان مدیر هم ثبت می‌شود (`setMyCommands` فقط برای گفت‌وگوی خود او)؛ کاربران عادی دستورهای مدیریتی را در منوی خود نمی‌بینند؛ منوی آن‌ها فقط `/start`، `/help`، `/music` و `/spotify` است ([جست‌وجو](music-search.md))، و منوی مدیر همان دو دستور جست‌وجو را آخر فهرست خودش هم دارد. فهرست فقط وقتی دوباره فرستاده می‌شود که دستورها یا توضیحشان عوض شده باشد، و اگر تلگرام نپذیرد پنل بدون مشکل باز می‌شود.

| دستور | کار |
| --- | --- |
| `/admin` | باز کردن پنل مدیریت |
| `/add_admin` | ادمین اصلی روی پیام کاربر ریپلای می‌کند و او را ادمین ربات می‌کند |
| `/delete_admin` | ادمین اصلی روی پیام ادمین ریپلای می‌کند و دسترسی او را می‌گیرد |
| `/list_admin` | فهرست ادمین‌های اصلی و اضافه‌شده؛ بدون نیاز به ریپلای و مخصوص ادمین اصلی |
| `/health` | وضعیت ربات، آمار و گزارش‌ها ([reports.md](reports.md)) |
| `/cookies` | ایمپورت و بررسی کوکی‌ها ([cookies.md](cookies.md)) |
| `/update` | به‌روزرسانی یا بازگشت نسخه، برای مدیران ربات در گروه هم ([updates.md](updates.md)) |
| `/customize` | شخصی‌سازی متن‌ها و دکمه‌ها |
| `/id` | نمایش شناسهٔ عددی حساب |
| `/help` | راهنمای کاربر |
| `/cancel` | لغو کار در حال انتظار و بازگشت |
| `/start` | منوی اصلی |

## مدیریت ادمین با ریپلای

دو دستور ریپلای در پی‌وی و گروه/تاپیک فعال کار می‌کنند و فقط حساب‌های اصلیِ `ADMIN_IDS` حق اجرای آن‌ها را دارند. آیدی عددی را تایپ نمی‌کنی؛ حساب واقعی فرستندهٔ پیام ریپلای‌شده انتخاب می‌شود و نیازی به نام کاربری یا Start قبلی ندارد. پیام‌های ربات، کانال، فرستندهٔ ناشناس و ریپلای خارجی پذیرفته نمی‌شوند. متن فورواردشده، حساب اصلیِ فوروارد را هدف نمی‌گیرد؛ ملاک همان فرستندهٔ پیام محلی است. دستور خطاب به ربات دیگر نادیده گرفته می‌شود.

ثبت تکراری نقش را بازنویسی نمی‌کند؛ حذف کاربر غیرادمین نیز چیزی را تغییر نمی‌دهد. ادمین‌های اصلی از داخل ربات قابل حذف نیستند. حذف ادمین، دسترسی‌های مدیریتی وابسته به او را هم لغو می‌کند و تعدادشان در نتیجه گفته می‌شود؛ شاخهٔ ادمین اصلی مستقل حفظ می‌شود و افزودن دوباره، دسترسی‌های لغوشده را برنمی‌گرداند. سایر مسیرهای ربات و worker مجوز را از همان پایگاه داده می‌خوانند.

متن‌های جدید از **شخصی‌سازی ← تنظیمات عمومی ← 👑 متن‌های مدیریت ادمین** ویرایش، پیش‌نمایش و ریست می‌شوند. متغیرهای `{user}` و `{id}` به حساب هدف اشاره دارند، `{command}` دستور راهنما و `{count}` تعداد دسترسی‌های وابستهٔ لغوشده است. طبق درخواست کاربر فقط متن‌های این دو دستور استثنائاً قابل شخصی‌سازی‌اند؛ متن‌های پنل قدیمی همچنان خارج از فهرست‌اند. افزودن قبلی با نام کاربری از پنل خصوصی هم باقی است.

دستور `/list_admin` در پی‌وی یا گروه/تاپیک، فهرست ادمین‌های فعال را با لینک حساب و نوع دسترسی نشان می‌دهد. فقط ادمین اصلی می‌تواند آن را اجرا کند. هر صفحه تا ۱۰ حساب دارد؛ ادامه با `/list_admin 2` و شماره‌های بعدی است. حساب‌های حذف‌شده یا دسترسی‌های نامعتبر و وابستهٔ لغوشده در فهرست نمی‌آیند. از شناسه‌های مجاز فعلی و نام‌های کاربری مشاهده‌شده استفاده می‌شود و برای هر حساب درخواست شبکه ارسال نمی‌شود. متن عنوان، ردیف‌ها، نوع دسترسی و راهنمای ادامه هم در بخش شخصی‌سازی مدیریت ادمین قابل ویرایش‌اند.

## افزودن دستور تازه

دستور تازه یک نام در `AdminCommands::LIST` (`src/AdminCommands.php`) و یک متن `admin_cmd_<نام>` در `resources/ui.json` با `audience: admin` می‌خواهد. پیام پنل و منوی «/» از همین فهرست ساخته می‌شوند، پس از هم جدا نمی‌مانند. خود دستور را در `Bot::message` مسیردهی کن.
