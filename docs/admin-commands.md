# دستورهای مدیر

وقتی **⚙️ پنل مدیریت** را باز می‌کنی (دکمه یا `/admin`)، پیام پنل این‌ها را نشان می‌دهد:

- **📜 دستورها:** فهرست همهٔ دستورهای مدیر با یک توضیح کوتاه، به‌شکل قابل‌لمس.
- **🧭 راهنمای استفاده:** چند خط کوتاه دربارهٔ دکمه‌ها، گزارش‌ها، کوکی‌ها، افزودن مدیر و `/cancel`.

همان فهرست در منوی «/» تلگرام همان مدیر هم ثبت می‌شود (`setMyCommands` فقط برای گفت‌وگوی خود او)؛ کاربران عادی دستورهای مدیریتی را در منوی خود نمی‌بینند؛ منوی آن‌ها فقط `/start`، `/help`، `/music` و `/spotify` است ([جست‌وجو](music-search.md))، و منوی مدیر همان دو دستور جست‌وجو را آخر فهرست خودش هم دارد. فهرست فقط وقتی دوباره فرستاده می‌شود که دستورها یا توضیحشان عوض شده باشد، و اگر تلگرام نپذیرد پنل بدون مشکل باز می‌شود.

| دستور | کار |
| --- | --- |
| `/admin` | باز کردن پنل مدیریت |
| `/health` | وضعیت ربات، آمار و گزارش‌ها ([reports.md](reports.md)) |
| `/cookies` | ایمپورت و بررسی کوکی‌ها ([cookies.md](cookies.md)) |
| `/update` | به‌روزرسانی یا بازگشت نسخه، برای مدیران ربات در گروه هم ([updates.md](updates.md)) |
| `/customize` | شخصی‌سازی متن‌ها و دکمه‌ها |
| `/id` | نمایش شناسهٔ عددی حساب |
| `/help` | راهنمای کاربر |
| `/cancel` | لغو کار در حال انتظار و بازگشت |
| `/start` | منوی اصلی |

## افزودن دستور تازه

دستور تازه یک نام در `AdminCommands::LIST` (`src/AdminCommands.php`) و یک متن `admin_cmd_<نام>` در `resources/ui.json` با `audience: admin` می‌خواهد. پیام پنل و منوی «/» از همین فهرست ساخته می‌شوند، پس از هم جدا نمی‌مانند. خود دستور را در `Bot::message` مسیردهی کن.
