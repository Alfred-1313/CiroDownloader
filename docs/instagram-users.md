# پروفایل مستقیم اینستاگرام

جست‌وجوی فهرستی حذف شده است. دستور `/user_instagram eliyas_sport` مستقیماً عکس پروفایل و بیوی **همان آیدی دقیق** را در پیام وضعیت نشان می‌دهد؛ نیازی به انتخاب حساب از فهرست نیست. در پی‌وی می‌توان فقط `eliyas_sport` یا `@eliyas_sport` را فرستاد. لینک پروفایل مثل `https://www.instagram.com/eliyas_sport/` هم در پی‌وی و هم گروه کار می‌کند؛ در گروه از دستور یا لینک کامل استفاده کن تا نوشته‌های عادی گروه به درخواست تبدیل نشوند.

کلید **🎨 شخصی‌سازی ← 📷 اینستاگرام ← ⚙️ تنظیمات ← 👤 نمایش پروفایل اینستاگرام** همان مقدار ذخیره‌شدهٔ کلید قبلی جست‌وجو را حفظ می‌کند؛ پیش‌فرض خاموش است. عکس، نام، نام کاربری، تعداد پست و فالوور/دنبال‌شونده و بیو در کپشن می‌آیند. عدد اعلام‌نشده «نامشخص» است. عکس ناموجود یا ردشده باعث از دست رفتن بیوی دریافت‌شده نمی‌شود. نام حساب برگشتی باید با آیدی درخواست‌شده تطبیق داشته باشد.

خواندن پروفایل فقط صفحهٔ همان حساب و در صورت نیاز query فعلی پروفایل gallery-dl را به کار می‌گیرد؛ هیچ topsearch یا API فهرست کاربران فراخوانی نمی‌شود و پست‌ها/فالوورها پیمایش نمی‌شوند. کوکی ورود از همان مخزن اینستاگرام و پروکسی از `GALLERY_PROXY` گرفته می‌شود. برای خروج از محدودیت 429 درخواست‌های جایگزین پشت‌سرهم اجرا نمی‌شوند؛ تغییر روش به‌تنهایی محدودیت اینستاگرام را رفع نمی‌کند.

کپشن، راهنما/خطا و دکمه‌های پروفایل از **اینستاگرام ← 👤 کپشن، متن‌ها و دکمه‌های پروفایل** و چیدمان از **چیدمان دکمه‌ها ← زیر پروفایل اینستاگرام** ویرایش می‌شوند. متغیرهای کپشن: `{name}`، `{username}`، `{posts}`، `{followers}`، `{following}`، `{privacy}` و `{bio}`. تنظیمات عمومی نمایش منبع اینستاگرام، دکمهٔ بازکردن حساب را کنترل می‌کند و پیش‌فرض خاموش است.

وقتی دانلود استوری روشن باشد، **📥 دانلود استوری‌ها** زیر پروفایل می‌آید. فقط درخواست‌دهنده در همان گفت‌وگو/موضوع می‌تواند از آن استفاده کند. دکمه یک درخواست جدا ایجاد می‌کند، عکس پروفایل را نگه می‌دارد و کلیک دوباره در زمان پردازش، دانلود تکراری نمی‌سازد. کنترل‌های پروفایل یک ساعت اعتبار دارند؛ کنترل‌های قدیمی فهرست کاربران بازنشسته‌اند و راهنمای ارسال دوبارهٔ آیدی می‌دهند.

عکس محلی پس از تأیید Telegram آزاد می‌شود. پروفایل/خطای خام به لاگ یا تاریخچهٔ خطا وارد نمی‌شود؛ اعلان خصوصی مدیر فقط مرحلهٔ ثابت و کد عددی HTTP دارد. تست‌های HTTP محلی، ساختار پاسخ و ارسال multipart را بررسی می‌کنند؛ دسترسی زنده به نشست و IP سرور وابسته است.
