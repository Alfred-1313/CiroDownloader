# Pornhub

ویدیوی Pornhub با همان روند یوتیوب دانلود می‌شود: لینک ← پوستر و انتخاب کیفیت ← دانلود و ارسال در همان پیام وضعیت.

## روشن کردن

**🎨 شخصی‌سازی ← ⚙️ قابلیت‌ها و محدودیت‌ها ← 🔞 سایت بزرگسال**

- **🔞 Pornhub:** پیش‌فرض **خاموش**. تا روشن نشود، لینک برای همه (حتی مدیر) مثل لینک پشتیبانی‌نشده جواب می‌گیرد.
- **👮 فقط مدیرها:** پیش‌فرض **روشن**. کاربر عادی همان پیام «لینک نامعتبر» را می‌بیند و چیزی دربارهٔ سایت نمی‌فهمد. با خاموش کردنش همهٔ کاربرها در پی‌وی می‌توانند استفاده کنند.
- **فقط پی‌وی:** در گروه‌ها هیچ‌وقت کار نمی‌کند و لینک نادیده گرفته می‌شود.
- اگر بعد از ثبت لینک خاموش شود، چیزی دانلود نمی‌شود.

## چه چیزی پذیرفته می‌شود

فقط صفحهٔ یک ویدیو: `pornhub.com/view_video.php?viewkey=...` (با `www`، `m` یا زیردامنهٔ زبان) و `pornhub.com/embed/...`. کانال، مدل، پلی‌لیست و دامنه‌های دیگر رد می‌شوند.

## کیفیت، سرعت و حجم

- منو مثل یوتیوب است: **پوستر ویدیو** با عنوان، دکمه‌های کیفیت (**240، 480، 720، 1080** هر کدام که صفحه دارد و در سقف ارسال جا می‌شود) و دکمهٔ **🎶 Audio** (MP3 صدای ویدیو).
- **پوستر** را خود ربات از سایت می‌گیرد و به‌صورت فایل برای تلگرام می‌فرستد؛ تلگرام همیشه نمی‌تواند عکس را از CDN سایت بردارد.
- **سرعت:** سایت برای هر کیفیت دو فایل می‌دهد: یک MP4 ساده که CDN آن را حدود 500 کیلوبایت در ثانیه محدود می‌کند، و یک جریان HLS که در تکه‌های هم‌زمان (هشت‌تا) دانلود می‌شود. ربات اول HLS را امتحان می‌کند و MP4 ساده فقط پشتیبان است. پیش از این اصلاح، MP4 کند اول می‌آمد و یک ویدیوی 16 دقیقه‌ای چند دقیقه طول می‌کشید.
- حجم کیفیت‌ها از اندازه یا نرخ بیت اعلام‌شدهٔ HLS (یا نرخ بیت داخل نام فایل) حساب می‌شود؛ کیفیتی که از سقف ارسال بزرگ‌تر است نشان داده نمی‌شود. اگر هیچ کیفیتی جا نشود، پیام «حجم زیاد» می‌آید.
- با تلگرام معمولی سقف 50 مگابایت است. برای ویدیوهای بزرگ‌تر [Local Bot API](large-uploads.md) لازم است (سقف 1990 مگابایت). سرعت ارسال به تلگرام را پهنای باند خروجی سرور مشخص می‌کند.
- صفحه بدون کوکی یوتیوب خوانده می‌شود؛ اگر `GALLERY_PROXY` تنظیم شده باشد از آن استفاده می‌شود ([network.md](network.md)).

## کپشن

کپشن پیش‌فرض (بدون لینک سایت و بدون دکمه):

```
🔞 عنوان ویدیو                 ← بولد
👤 بازیگر۱، بازیگر۲             ← pornstarهای صفحه؛ اگر نبود، نام کانال یا کاربر
⏱ 16:42 · 🎞 480p · 👁 763,850   ← Quote
🏷 #دسته #برچسب ...              ← Quote جمع‌شده، تا جایی که در 1024 نویسه جا شود
```

ویدیو توضیح جدایی ندارد؛ «کپشن ویدیو» همان عنوان و برچسب‌های صفحه است. متن‌ها در **🎨 شخصی‌سازی ← 🔞 Pornhub** قابل تغییرند (`{title}`، `{people}`، `{views}`، `{tags}`). آمار و خطاها در «📊 وضعیت ربات» با نام Pornhub ثبت می‌شوند.

## یادآوری

تلگرام با ربات‌هایی که محتوای بزرگسال پخش می‌کنند سخت‌گیر است و قانون بسته به کشور فرق دارد؛ مسئولیت روشن کردن این قابلیت با مدیر است.

## اگر «اتصال سرور به سایت برقرار نشد» آمد

این پیام یعنی سرور به صفحهٔ سایت نرسیده است. علت دقیق را مدیر در **📊 وضعیت ربات** (قسمت «آخرین خطا») و **🚨 خطاها** به‌صورت یک کلمه می‌بیند، مثل `pornhub=certificate`. هیچ آدرس یا خروجی خام ذخیره نمی‌شود.

| کلمه | معنی | چه کنم |
| --- | --- | --- |
| `certificate` | گواهی سایت معتبر نیست؛ معمولاً شبکه یا ارائه‌دهندهٔ سرور سایت را مسدود کرده و صفحهٔ دیگری نشان می‌دهد | پراکسی/VPN بیرون از آن شبکه |
| `dns` | نام سایت پیدا نشد (DNS مسدود یا خراب) | DNS دیگر یا پراکسی |
| `refused`, `unreachable`, `reset`, `timeout` | اتصال قطع، رد یا خیلی کند است | پراکسی؛ اگر موقتی است بعداً دوباره |
| `region` | سایت در منطقهٔ سرور در دسترس نیست (451) | پراکسی در منطقهٔ دیگر |
| `forbidden`, `ratelimit` | سایت این IP را رد یا محدود کرده است | پراکسی با IP دیگر |
| `gone` | سایت «410 Gone» داده: یا ویدیو حذف شده، یا (رایج‌تر) سایت **این IP یا منطقه** را رد کرده است. اگر همان لینک روی گوشی باز می‌شود، سرور مسدود است | پراکسی در منطقه‌ای که سایت در آن باز است |
| `unavailable` | خطای سمت سایت (5xx) | بعداً دوباره |
| `page` | ساختار صفحه یا تأیید سن تغییر کرده؛ yt-dlp را به‌روز کن | به‌روزرسانی |

پراکسی را با `GALLERY_PROXY` در `.env` بده ([network.md](network.md)). این پراکسی برای Pornhub، اینستاگرام، پینترست، تیک‌تاک و X استفاده می‌شود و برای تلگرام نه. بعد از تغییر `.env` سرویس را دوباره راه‌اندازی کن.

### آزمایش مستقیم روی سرور

```bash
docker compose exec worker /opt/yt/bin/yt-dlp --ignore-config --no-playlist --skip-download --no-warnings --print title "LINK"
```

اگر `Unable to download webpage: HTTP Error 410: Gone` آمد ولی لینک روی گوشی باز می‌شود، سایت منطقهٔ سرور را مسدود کرده است. با پراکسی امتحان کن:

```bash
docker compose exec worker /opt/yt/bin/yt-dlp --ignore-config --no-playlist --skip-download --no-warnings --proxy "socks5h://HOST:PORT" --print title "LINK"
```

اگر این عنوان را چاپ کرد، همان آدرس را در `GALLERY_PROXY` بگذار.

### «410 Gone» از سرور ابری

بعضی سایت‌ها درخواستی را که شبیه ابزار (و نه مرورگر) باشد از IP سرورهای ابری با `410 Gone` یا `403` رد می‌کنند. yt-dlp برای همین می‌تواند خودش را شبیه مرورگر Chrome معرفی کند (impersonation)، به شرطی که بستهٔ `curl-cffi` نصب باشد. از نسخهٔ 1.43.2 تصویر Docker همین بسته را دارد (`yt-dlp[default,curl-cffi]`)؛ پیش از آن yt-dlp هشدار می‌داد «`The extractor is attempting impersonation, but no impersonate target is available`». برای اعمالش باید تصویر دوباره ساخته شود (`CiroDownloader update`). اگر بعد از آن هم همان 410 آمد، سایت خود IP سرور را مسدود کرده و فقط پراکسی کمک می‌کند.
