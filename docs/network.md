# مسیر خروجی: پراکسی و PO Token

بیشتر خطاهای «ورود لازم است» و «ربات نیستم» از **IP سرور** می‌آیند، نه از کوکی. وقتی سرویس IP دیتاسنتر را مشکوک می‌داند، کوکی تازه هم همیشه کافی نیست. این صفحه دو ابزار برای همین مشکل را توضیح می‌دهد. هیچ‌کدام به‌طور پیش‌فرض روشن نیست.

## پراکسی یوتیوب

در `.env`:

```dotenv
YOUTUBE_PROXY=socks5://HOST:PORT
```

یا از منوی مدیریت سرور: **Settings ← YouTube proxy**. پراکسی فقط برای یوتیوب است، نه تلگرام.

## پراکسی اینستاگرام، پینترست، تیک‌تاک و X

```dotenv
GALLERY_PROXY=socks5h://HOST:PORT
```

یا از منوی مدیریت سرور: **Settings ← Social media proxy**. آدرس‌های `http://`، `https://`، `socks5://` و `socks5h://` پذیرفته می‌شوند. این پراکسی به‌صورت `--proxy` به gallery-dl داده می‌شود و ویدیوهای HLS آن (که yt-dlp داخلی gallery-dl دریافت می‌کند) هم از همان استفاده می‌کنند. برای حذف، در منو `clear` را وارد کن. وضعیت (بدون نمایش آدرس) در `/health` دیده می‌شود.

نکته: `127.0.0.1` داخل کانتینر به خود کانتینر اشاره می‌کند؛ پراکسی باید از داخل Docker قابل دسترس باشد.

## PO Token برای یوتیوب (اختیاری)

یوتیوب برای بعضی درخواست‌ها «PO Token» می‌خواهد و yt-dlp آن را خودش نمی‌سازد. پروژهٔ [bgutil-ytdlp-pot-provider](https://github.com/Brainicism/bgutil-ytdlp-pot-provider) (مجوز GPL-3.0) این توکن را در یک کانتینر جدا می‌سازد و yt-dlp با افزونه‌اش آن را می‌گیرد.

1. در `.env` این دو را بگذار:
   ```dotenv
   YOUTUBE_POT_PLUGIN=1
   YOUTUBE_POT_URL=http://pot:4416
   ```
2. از پوشهٔ پروژه اجرا کن:
   ```bash
   docker compose --profile pot up -d --build
   ```
3. با یک لینک یوتیوب آزمایش کن و در صورت خطا `docker compose logs worker` و `docker compose logs pot` را ببین.

جزئیات:

- افزونه با نسخهٔ `2.0.2` و کانتینر با برچسب `2.0.2-deno` ثابت شده‌اند. هیچ پورتی به بیرون باز نمی‌شود؛ ربات فقط از شبکهٔ داخلی Docker به `pot:4416` می‌رسد.
- بدون `YOUTUBE_POT_URL`، به yt-dlp چیزی اضافه نمی‌شود و رفتار قبلی حفظ می‌ماند.
- **این قابلیت را روی IP محدودشده آزمایش نکرده‌ام.** توکن، مسدودشدن IP را برطرف نمی‌کند؛ اگر IP سرور بلاک است، پراکسی مناسب‌تر است. README پروژهٔ مبدأ هم نمی‌گوید اگر سرور توکن در دسترس نباشد چه می‌شود. پس بعد از روشن‌کردن حتماً با لینک واقعی بسنج.
- وضعیت (بدون آدرس) در `/health` با «PO Token یوتیوب» دیده می‌شود.
